# duo-repent (듀오 반성해)

지금 쓰는 갤럭시·아이폰 브라우저에서 아이폰 듀오의 단점을 미리 겪어보는 비공식 체험 웹앱.

- 접힌 외부 화면(5.4″) / 펼친 내부 화면(7.6″) 비율 재현
- 미최적화 앱 검은 바, 캡처 시 검은 바 겹침, 크랙게이트 균열, 오른쪽 몰린 UI
- 측면 Touch ID 잠금, 발열, 나노텍스처, 254g 무게 비교
- 듀오 가격으로 살 수 있는 것 비교표 (커피, 그래픽카드, CPU, Claude Pro 등)

단일 파일 `index.html` — 브라우저로 열면 바로 동작. 애플과 무관한 비공식 시뮬레이션.
